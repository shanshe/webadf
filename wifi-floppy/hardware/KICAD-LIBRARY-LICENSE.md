the official KiCad libraries (https://gitlab.com/kicad/libraries), © KiCad Library Team.

a design, and distributing the design's output (schematics, PCB layouts, Gerbers, BOMs), does not by itself put the
design under CC-BY-SA. Changes to the library files themselves remain under CC-BY-SA 4.0.

The board design itself (schematic, PCB, production files) is licensed separately; see the Licence section of the
repository README.
